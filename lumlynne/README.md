# Lumlynne v0.1
DON'T SWIPE. TALK.

Protótipo de chat aleatório por texto com pareamento por idioma, troca de parceiro e botão de denúncia.

## Executar
Node.js 20+: entre em `lumlynne`, execute `npm install` e `npm start`. Abra http://localhost:3000 em duas abas e escolha o mesmo idioma.

## Antes de publicar
**Não está pronto para uso público.** Falta moderação efetiva, armazenamento e análise de denúncias, verificação de idade, bloqueio, limitação de tráfego, políticas de privacidade, autenticação e testes. O botão de denúncia registra um evento no servidor, mas não aplica banimento. Vídeo e PWA ainda não foram feitos. O serviço requer hospedagem com suporte a WebSockets persistentes.
